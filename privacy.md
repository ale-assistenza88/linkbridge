# LinkBridge Privacy Policy

**Last updated: August 30, 2026**

LinkBridge is a browser extension designed to help users process links from supported container pages and copy the resolved destination URLs for use with a download manager.

## How LinkBridge Works

After the user manually completes any CAPTCHA or other challenge required by a supported website, LinkBridge can detect the links made available by the container page.

When the user explicitly starts the resolution process, LinkBridge follows the relevant redirects in order to determine the destination URLs and can copy the resolved URLs to the clipboard.

LinkBridge does not bypass CAPTCHAs, authentication systems, paywalls, access restrictions, or limitations imposed by third-party services.

## Data Processing

LinkBridge performs its processing locally in the user's browser.

LinkBridge does not operate a server that receives or stores resolved links, browsing information, or other user data.

LinkBridge does not require a LinkBridge account.

## Local Storage

LinkBridge may store limited information locally in the browser that is necessary for its operation, including:

- the current supported container state;
- detected container links;
- resolved destination URLs;
- unresolved or failed results;
- extension interface state.

This information is used only to provide the extension's functionality and is not transmitted to a LinkBridge server.

## Website Access

LinkBridge requires access to supported FileCrypt container domains in order to detect container links.

When the user explicitly starts link resolution, LinkBridge may request permission to access external HTTP and HTTPS websites. This is necessary because container links can redirect to destination hosts that cannot be known in advance.

Network requests made during resolution are sent directly from the user's browser to the relevant websites.

LinkBridge does not use this access to monitor the user's general browsing activity.

## Clipboard

LinkBridge may write resolved destination URLs to the user's clipboard after the user initiates the resolution process.

Clipboard access is used only to provide the link-copying functionality of the extension.

## Analytics and Tracking

LinkBridge does not use analytics, advertising trackers, tracking pixels, or behavioral profiling.

LinkBridge does not sell user data.

## Data Sharing

LinkBridge does not sell, rent, or transfer user data to third parties for advertising, profiling, creditworthiness, lending, or other unrelated purposes.

Requests made directly to supported container websites and destination websites are subject to the privacy policies and terms of those third-party services.

## Remote Code

LinkBridge does not download or execute remote code as part of the extension.

The executable code required for LinkBridge is included in the extension package distributed through the Chrome Web Store.

## Third-Party Services

LinkBridge is an independent project and is not affiliated with, endorsed by, or sponsored by FileCrypt, JDownloader, or any file-hosting provider.

Users are responsible for using LinkBridge only with websites, services, and content they are authorized to access.

## Changes to This Privacy Policy

This Privacy Policy may be updated if LinkBridge's functionality or data practices change. The latest version will always be published on this page.
